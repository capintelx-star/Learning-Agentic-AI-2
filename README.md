# Learning-Agentic-AI

I'm a business analyst learning to build with AI. This repo is the public log of how that goes.

---

## Why this exists

Two reasons:

1. **Commitment device.** Putting it in public to hold myself accountable
2. **Receipts.** I want a trail of the work that I've done to measure my progress and help people in the future who are starting from the same position as me

I've already shipped a couple projects and code that I don't fully understand (Polymarket arb bots, learning apps, browser extensions). The gap I'm closing here is the jump from "vibe-coded prototype" to "agentic systems I designed deliberately."

## Who I am

Business analyst with a background in finance and analytics. I've been shipping side projects with Claude Code for a while, mostly around financial markets, prediction markets, and content automation. All of it has been slop, but I have learned some of the basics by doing it.

What I want to be able to do by week 12: design and ship agentic systems end-to-end — not just call an LLM in a loop, but build things that plan, use tools, recover from failure, and produce real outputs I'd trust.

## How this repo is organized

/weekly      One file per week. Goals, what shipped, what broke, lessons.
/projects    The actual builds. Each in its own subfolder with its own README.
/prompts     System prompts and Claude Project instructions worth keeping.
/notes       Concepts, patterns, references I want to find again later.

## The 12-week shape (rough)

- **Weeks 1–3:** Foundations — agentic patterns, tool use, structured outputs, evals
- **Weeks 4–7:** Build phase — two to three real agentic projects, shipped
- **Weeks 8–10:** Depth — multi-agent, longer-horizon tasks, harder eval problems
- **Weeks 11–12:** Synthesis — pick the best work, polish it, write it up

Expect this to change. That's part of the point.
